# Toggle Text (ON / OFF)

## Description
A simple mini project that uses HTML, CSS, and JavaScript to toggle text between **ON** and **OFF** when a button is clicked.

## Features
- Centered layout using Flexbox
- Responsive design for all screen sizes
- Dynamic text change with JavaScript

## How It Works
- Page loads with **OFF**
- Click **Toggle** → text changes to **ON**
- Click again → text changes back to **OFF**

## Technologies
- HTML
- CSS
- JavaScript

## Run
Open `index.html` in a web browser
