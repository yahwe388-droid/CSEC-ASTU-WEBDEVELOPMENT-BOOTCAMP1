# CSEC-ASTU MiniProject 2

## Overview
A small front-end mini project created for the CSEC ASTU Web Development Bootcamp. This project demonstrates a simple static webpage with responsive styling.

## Features
- Single-page layout using HTML and CSS
- Responsive styles for basic devices
- Clean, minimal design for learning and extension

## Files
- `index.html` — main HTML page
- `style.css` — styling for the page

## How to run
1. Open the project folder.
2. Open `index.html` in your preferred web browser (double-click or right-click → Open with → Browser).

## Technologies
- HTML5
- CSS3

## How to customize
- Edit `index.html` to change content and structure.
- Modify `style.css` to update layout, colors, and responsive rules.
