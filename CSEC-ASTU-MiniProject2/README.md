# Personal Profile Page - Mini Project

🎯 CSEC ASTU Mini Project 2: Personal Profile Webpage

A responsive personal profile webpage built with pure HTML and CSS, demonstrating modern web development techniques and responsive design principles.

## 🚀 Live Demo
View Live Website

## 📋 Project Overview
This project is a personal portfolio website showcasing my skills, interests, and contact information as a Software Engineering student at ADAMA SCIENCE AND TECHNOLOGY UNIVERSITY (ASTU).

## 🎨 Features

### ✅ Completed Requirements:
- Header Section: Name & title with proper text styling
- Profile Section: Image & bio using Flexbox layout
- Skills Section: 5 skill cards arranged with CSS Grid
- Contact Section: Fully functional contact form with validation
- Footer: Copyright and social media links
- Responsive Design: Mobile-first approach with media queries

### 🛠️ Technologies Used:
- HTML5: Semantic markup and structure
- CSS3: Styling with custom properties (CSS Variables)
- JavaScript: Form validation and interactivity
- Google Fonts: Poppins and Raleway typography
- Font Awesome: Icon library for visual elements

### Responsive Design:
- Mobile-first approach
- Media queries for different screen sizes
- Flexbox stacking on mobile
- Grid column adjustment (3 → 2 → 1 columns)

### Styling Features:
- CSS Custom Properties (Variables)
- Hover effects and transitions
- Background images with gradient overlay
- Box shadows and border-radius
- Text transformations and alignments

## 📱 Responsive Breakpoints
- Desktop: 1200px+ (3-column grid)
- Tablet: 768px - 992px (2-column grid)
- Mobile: < 768px (1-column grid, stacked layout)
